> [!CAUTION]
> This is an unofficial, experimental extension. ppy does not allow rulesets that are not game modes or unofficial mirror downloads inside the game. See [peppy's statement](https://osu.ppy.sh/community/forums/topics/2208577).

Download beatmaps from Sayobot and import them directly within **osu!lazer 2026.1005.0 stable**.

- Uses the normal download buttons, with optional fallback to the official source.
- Supports downloads without video, system proxies, and manual beatmap set IDs or links.
- Includes English, Traditional Chinese, Simplified Chinese, and Japanese interfaces.
- Automatically closes native cancellation notifications caused by interception.
- Keeps handled download failures in the local log without forwarding them to error-reporting listeners.
- Starts quietly without a startup notification.

Install `osu.Game.Rulesets.Sayobot.dll` in the `rulesets` subfolder of your osu! data folder, then restart lazer. The ZIP contains the same DLL and English documentation. Existing installations can replace the DLL directly.

Validation: 18 offline tests passed, along with a local headless integration test covering a real Sayobot download, Realm import, notification cleanup, and official fallback. Windowed UI coverage and other platforms remain incomplete; see `VALIDATION.md` in the package.
